Ember Valley — a spot-the-difference game: three mountain-village seasons (a dawn village, an autumn camp, a snowy lantern night), seven differences hidden in each scene. Find all 7 to clear the scene; beat the par time to earn 3 stars.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8081 in a desktop browser.
